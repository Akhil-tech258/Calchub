# 🧮 CalcHub — 100+ Multi-Category Calculator Hub & PWA

CalcHub is a high-performance, mobile-first Progressive Web App (PWA) hosting a comprehensive suite of over 100+ free online calculators spanning Finance, Health & Fitness, Academic, Math, Engineering, and Everyday utilities—zero sign-up required, working fully offline.

---

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Modern CSS3 (Glassmorphism, CSS Custom Properties, Fluid Typography, Responsive Grid & Flexbox)
- **Engine & Architecture:** Vanilla JavaScript (ES6+, Modular Calculator Calculation Engine, Custom Math Parsers)
- **Search System:** In-memory client-side substring & keyword fuzzy search engine
- **PWA & Offline:** Native Service Worker (`sw.js`) for cache-first offline capability, Web App Manifest (`manifest.json`) for installability
- **Storage:** Browser `localStorage` for Starred Favorites, Recent Calculators, and Theme Preferences
- **SEO & Metadata:** OpenGraph tags, Twitter cards, and Schema.org JSON-LD Structured Data
- **Deployment:** GitHub Pages

---

## ✨ Features

- 📂 **10+ Curated Utility Categories:**
  - 💰 **Finance & Investment:** EMI, SIP, Compound Interest, Loan Comparison, GST, Salary/Tax breakdown.
  - 🏋️ **Health & Fitness:** BMI, BMR, Calorie Expenditure, Ideal Weight, Water Intake.
  - 🎓 **Academic & Student:** CGPA to Percentage, GPA Semester, Attendance Margin, Final Grade Calculator.
  - 📐 **Mathematics & Science:** Scientific Calculator, Fractions, Percentage Increase/Decrease, Quadratic Equations.
  - 💻 **Developers & Productivity:** Binary/Hex/Decimal Converter, Aspect Ratio, Unix Timestamp, Unit Converters.

- 🔍 **Real-Time Live Search:**
  - Type-ahead search box immediately matches calculator titles, keywords, and synonyms (e.g. searching *"home loan"* finds *EMI Calculator*).

- ⭐ **Favorites & Recents Shelf:**
  - Star frequently used calculators for one-click access on the homepage dashboard.
  - Automatically records recently visited calculators in `localStorage`.

- ⚡ **Offline-Ready Progressive Web App (PWA):**
  - Installable directly to mobile home screens and desktop app shelves.
  - Core calculation algorithms execute 100% client-side without internet access once cached.

- 🌓 **Adaptive Dark & Light Themes:**
  - Smooth glassmorphism theme engine respecting system color scheme preferences.
